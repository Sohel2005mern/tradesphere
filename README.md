# TradeSphere

TradeSphere is a full-stack stock trading platform built using the MERN stack. It allows users to manage their stock portfolio by buying and selling stocks, tracking holdings and positions, and viewing their investment summary through an interactive dashboard.

## Features

- User authentication using JWT
- Buy and sell stocks
- Portfolio management
- Holdings and positions tracking
- Interactive dashboard
- RESTful APIs
- Responsive user interface

## Tech Stack

## Getting Started

### Clone the repository

```bash
git clone https://github.com/Sohel2005mern/tradesphere.git
```

### Install dependencies

Backend

```bash
cd backend
npm install
```

Frontend

```bash
cd frontend
npm install
```

Dashboard

```bash
cd dashboard
npm install
```

### Environment Variables

Create a `.env` file inside the **backend** folder and add:

```env
MONGO_URL=your_mongodb_connection_string
JWT_SECRET=your_jwt_secret
```

### Run the project

Backend

```bash
npm start
```

Frontend

```bash
npm start
```

Dashboard

```bash
npm start
```
